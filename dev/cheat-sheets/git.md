# dev/cheatsheets/git.md

# BONUP GIT CHEAT SHEET

## STATUS
git status

## ADD
git add .
git add filename.py

## COMMIT
git commit -m "message"

## PUSH
git push origin main

## PULL
git pull origin main

## BRANCHES
git branch
git branch new-branch
git checkout new-branch
git checkout main

## REMOVE FILE FROM GIT TRACKING
git rm --cached filename

## VIEW HISTORY
git log --oneline
