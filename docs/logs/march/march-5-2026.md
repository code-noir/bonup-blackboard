4. Contract Aggregate Implemented

File:
backend/engine/contracts/domain/contract.py

The Contract domain entity now manages:
	•	contract_id
	•	obligations
	•	contract state aggregation

Responsibilities implemented:
	•	hold obligations
	•	apply payments
	•	run lifecycle updates
	•	aggregate contract state

Contract state rules:

If any obligation is breached or defaulted → contract = breached
If all obligations are resolved → contract = fulfilled
Otherwise → contract = active

	•	persist contract

Flow implemented:

Coordinator
→ load contract
→ load obligations
→ run lifecycle engine
→ attach obligations to contract
→ refresh contract state
→ save contract

Bug 3 — Payment Tracking Attribute Mismatch

Error:
amount_paid vs paid_amount mismatch.

Resolution:
Unified naming convention to use amount_paid.

⸻

Bug 4 — Lifecycle Resetting Resolved Obligations

Lifecycle engine was re-evaluating already resolved obligations and overwriting test setup.

Resolution:
Prevent lifecycle from overriding resolved state during coordinator refresh.

⸻

Bug 5 — Contract State Not Updating

Contract remained “active” even when obligations were resolved.

Cause:
Coordinator never refreshed contract state.

Resolution:
Coordinator now calls contract.refresh().

⸻

Bug 6 — Obligations Not Attached to Contract

Contract state aggregation failed because obligations were not linked to the contract.

Resolution:
Coordinator now explicitly attaches obligations:

contract.obligations = obligations
